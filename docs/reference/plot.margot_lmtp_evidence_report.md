# Plot an LMTP evidence report

Stacks the displays of the available components (censoring, projection
and full analysis weights) and lists each unavailable component with its
structural reason in the caption.

## Usage

``` r
# S3 method for class 'margot_lmtp_evidence_report'
plot(x, ...)
```

## Arguments

- x:

  A \`margot_lmtp_evidence_report\` object.

- ...:

  Ignored.

## Value

A \`patchwork\` object.
