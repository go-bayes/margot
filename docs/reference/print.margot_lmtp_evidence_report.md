# Print an LMTP evidence report

Prints the availability manifest with a one-line summary of each
available component and the structural reason for each unavailable one.
Print a component for its tables, or \`plot()\` the report for the
available displays.

## Usage

``` r
# S3 method for class 'margot_lmtp_evidence_report'
print(x, digits = 2, ...)
```

## Arguments

- x:

  A \`margot_lmtp_evidence_report\` object.

- digits:

  Decimal places for the component summaries.

- ...:

  Ignored.

## Value

\`x\`, invisibly.
