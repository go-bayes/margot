# Describe a stored policy-value gain and its practical margin

Describe a stored policy-value gain and its practical margin

## Usage

``` r
margot_text_policy_value_gain(data, digits = 3L)
```

## Arguments

- data:

  A validated object from
  [`margot_policy_reporting_data()`](https://go-bayes.github.io/margot/reference/margot_policy_reporting_data.md).

- digits:

  Decimal places for displayed numbers; raw tables retain full
  precision.

## Value

A character vector distinguishing the value estimate, supplied interval
and practical margin.
