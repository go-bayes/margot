# Plot an LMTP full analysis-weight report

Draws, for every node and stage, the Kish effective sample size as a
fraction of all rows, the maximum full analysis weight, and the share of
rows with a zero weight.

## Usage

``` r
# S3 method for class 'margot_lmtp_analysis_weight_report'
plot(x, ...)
```

## Arguments

- x:

  A \`margot_lmtp_analysis_weight_report\` object.

- ...:

  Ignored.

## Value

A \`ggplot\` object.
